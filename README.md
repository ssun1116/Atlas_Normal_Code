# Atlas_Normal_Code
Code repository for generating human brain transcriptome single-cell atlas in "An integrative single-cell atlas for exploring the cellular and temporal specicity of genes related to neurological disorders during human brain development" (https://doi.org/10.1038/s12276-024-01328-6).
- Updated code repository: The maintained version of this repository is available at https://github.com/joonan-lab/bts-atlas.
